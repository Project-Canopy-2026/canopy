## Some tips for maintaining the github repo. We can keep adding on to this!
### branching
- main — stable, always runnable
- Work on our own branch for each subsystem.
- main branch is protected, no direct push to main, use PR (Pull Request).
- Branch naming: type/subsystem/owner
    - dev/perception/shuyi
    - feature/perception/seedling-detection
    - fix/navigation/global-nav-bug
    - refactor/arm_control/trajectory-api
